# Repository cleanup

The cleanup targets generated files and the unused pre-refactor implementation. The active atlas, scripts, tests, three scenes, project settings, and save format are retained.

Removed from the working tree:

- `Legacy~/`: obsolete MonoBehaviour-based neural-network scripts, prefabs, duplicate textures, and the original scene. The active atlas remains at `Assets/Resources/DinoAtlas.png`.
- `Assets/Scenes/SampleScene.unity` and its metadata: an unused duplicate of MainMenu, absent from Build Settings.
- Root-level `.csproj`, `.sln`, and `.slnx` files: generated Unity/IDE projects with stale paths and references. The hand-written `Tests/CoreChecks/CoreChecks.csproj` is retained.
- Previously tracked files under `Logs/`, `Temp/`, `obj/`, and `UserSettings/`: logs, build caches, and machine-specific editor preferences. `.gitignore` already excludes regenerated copies.

Unused direct package dependencies removed:

- 2D Animation, Pixel Perfect, PSD Importer, Sprite, SpriteShape, and Tilemap.
- AI Navigation, Collaborate, Multiplayer Center, Timeline, and Visual Scripting.
- Rider and the deprecated VS Code integration.

UGUI, Unity Test Framework, Visual Studio integration, and the built-in Unity modules remain. The package lock is regenerated by Unity. The project renders directly from a texture atlas through UGUI and does not use the removed 2D packages or old prefabs.

No files outside the target project are deleted. Training data in Application.persistentDataPath is preserved. Original tracked content remains available in Git history and in a verified local backup ZIP made before cleanup.
