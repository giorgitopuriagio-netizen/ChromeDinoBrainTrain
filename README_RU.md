# ChromeDinoBrainTrain

[English README](README.md)

Unity **6000.3.8f1**. Открой `Assets/Scenes/MainMenu.unity` и нажми **Play** либо используй **Chrome Dino > Open Main Menu**. Интерфейс на английском, порядок выбора совпадает с FlappyBirdBrainTrain.

## Проверка проекта

1. **New training** запускает новую популяцию из 200 динозавров. Старые запуски остаются в архиве.
2. **x1 / x5 / x10 / x30** изменяют число шагов симуляции, сохраняя физику. Дождись окончания поколения или последнего выжившего.
3. **Stop and save** сохраняет и останавливает обучение. **Evaluate AI** открывает проверку.
4. В едином списке **Generation brain** доступны поколения всех запусков. Номер run различает одинаковые номера поколений.
5. **Course: new** выбирает новую трассу; **Course: selected generation** — трассу сохранённого победителя.
6. **Watch bot** сразу запускает бота. **Human vs bot** сразу создаёт состязание и ждёт первого прыжка человека. Отдельной кнопки Start нет.
7. Кнопки режима доступны и во время заезда: нажатие перезапускает выбранный режим с новым миром и очищенным вводом. Выбор поколения и трассы доступен после остановки или завершения заезда.
8. **Main menu > Continue training** восстанавливает поколение, популяцию, мир и состояния генераторов случайных чисел.

Пробел, **↑**, **W**, касание поля или **Jump / Space** — прыжок. Удержание увеличивает высоту. **↓**, **S** или удержание **Duck / Down** — пригнуться либо ускорить падение. Повторный прыжок требует приземления и нового нажатия.

Серый Dino — бот, синий — человек. Оба используют одинаковую физику и препятствия, не сталкиваются друг с другом. Выживший продолжает после гибели соперника. Побеждает проживший больше тактов; одновременная гибель — ничья. Ручная остановка победителя не назначает.

Потеря фокуса ставит обучение на паузу и сохраняет его; **Resume** продолжает обучение. Состязание после возврата ждёт нового прыжка, просмотр бота продолжается автоматически. **Esc** останавливает текущий режим.

## Нейросеть и сохранения

Общее ядро `Assets/Scripts/Core` — чистый C# без Unity. Один фиксированный шаг **1/60 с** используется в обучении и игре. Нейросеть **10 → 16 → 10 → 2** управляет прыжком и пригибанием. Генетический алгоритм использует турнирный отбор, равномерное скрещивание, аддитивные мутации, четыре неизменённых элиты и 5% новых случайных особей.

Сохранения лежат в `Application.persistentDataPath/Training/`. Полный checkpoint содержит мозги, мир и случайные состояния. Архив хранит победителей и последнего живого Dino незавершённого поколения. Автосохранение происходит каждые 30 секунд, после поколения, при паузе/потере фокуса и выходе. Доступно восстановление checkpoint, указателя последнего запуска и архива из `.bak`. Ошибка записи приостанавливает обучение и блокирует переход с несохранённым состоянием.

## Проверки и сборка

В Unity Test Runner запусти Edit Mode и Play Mode. Независимые проверки ядра из корня проекта:

```powershell
dotnet run --project Tests/CoreChecks/CoreChecks.csproj --configuration Release
dotnet run --project Tests/CoreChecks/CoreChecks.csproj --configuration Release -- --training-smoke
```

Этим двум командам нужен .NET SDK 10; игре Unity он не требуется. **Chrome Dino > Build Windows** создаёт `Builds/Windows/ChromeDino.exe`.

Активные сцены: `MainMenu`, `Training`, `AITest`. Старые префабы, скрипты, дублирующая сцена и генерируемые файлы удалены из состава репозитория. Исходные версии доступны в истории Git. Детали: [Docs/LOGIC_AUDIT.md](Docs/LOGIC_AUDIT.md).
